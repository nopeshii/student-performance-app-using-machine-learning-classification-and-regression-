
# Student Performance Prediction using Machine Learning

This project predicts student academic performance using Machine Learning techniques.

## Dataset

Students Performance Dataset (Kaggle)


🌐 Live Demo
👉 https://student-performance-mal.streamlit.app/

- Linear Regression

### Classification

- Decision Tree Classifier
- Logistic Regression

## Features Used

- Reading Score
- Writing Score

## Outputs

- Math Score Prediction
- Pass / Fail Prediction

- Confusion Matrix
