# Student Performance Prediction Using Machine Learning by ISHIT PATTNAIK

## 1. Introduction

Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions without being explicitly programmed. In the education sector, machine learning can be used to analyze student performance and predict academic outcomes.

This project focuses on predicting student performance using machine learning techniques. The model analyzes student reading and writing scores to predict mathematics performance and determine whether a student will pass or fail.

---

## 2. Objective

The main objectives of this project are:

* To understand the machine learning workflow.
* To perform data preprocessing and exploratory data analysis.
* To predict student mathematics scores using Linear Regression.
* To classify students as Pass or Fail using Classification algorithms.
* To compare the performance of different machine learning models.
* To visualize relationships among different student scores.

---

## 3. Dataset Description

### Dataset Name

Students Performance Dataset

### Source

Kaggle

### Number of Records

1000 Students

### Features Used

| Feature       | Description                   |
| ------------- | ----------------------------- |
| Reading Score | Marks obtained in Reading     |
| Writing Score | Marks obtained in Writing     |
| Math Score    | Marks obtained in Mathematics |

### Target Variables

#### Regression Target

* Math Score

#### Classification Target

* Pass/Fail Status
* Pass = Math Score ≥ 40
* Fail = Math Score < 40

---

## 4. Methodology

The project follows the standard Machine Learning workflow:

### Step 1: Data Collection

The student performance dataset was downloaded and loaded into Python using Pandas.

### Step 2: Data Exploration

The dataset was analyzed using:

* Shape of dataset
* Column information
* Statistical summary
* Missing value analysis

### Step 3: Data Preparation

The required features were selected:

* Reading Score
* Writing Score

For classification, a new column called Result was created:

* 1 = Pass
* 0 = Fail

### Step 4: Data Splitting

The dataset was divided into:

* Training Data (80%)
* Testing Data (20%)

### Step 5: Model Training

Machine Learning algorithms were trained using the training dataset.

### Step 6: Model Evaluation

Models were evaluated using standard evaluation metrics.

---

## 5. Algorithms Used

### A. Linear Regression

Linear Regression is a supervised learning algorithm used for predicting continuous numerical values.

Purpose:

* Predict Mathematics Score

Evaluation Metrics:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)

---

### B. Decision Tree Classifier

Decision Tree is a supervised learning algorithm used for classification tasks.

Purpose:

* Predict Pass/Fail Status

Evaluation Metric:

* Accuracy Score

---

### C. Logistic Regression

Logistic Regression is a classification algorithm used for predicting categorical outcomes.

Purpose:

* Compare classification performance with Decision Tree.

Evaluation Metric:

* Accuracy Score
